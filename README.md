# Duty Board home screen icons

Small launcher pages that give the Duty Board app its own home screen icon on iPhone.
Each page sets its icon and name, then sends you straight on to the app.

- `asim/`: Asim's own icon (teal ££)
- `view/`: the view-only icon for his wife (teal eye, "Asim's Rota")

To add one: open the page in Chrome or Safari, tap Share, then Add to Home Screen.
