# Work Rota & Ledger home screen icons

Small launcher pages that give the Work Rota & Ledger app its own home screen icon on iPhone.
Each page sets its icon and name, then sends you straight on to the app.

- `asim/`: Asim's own icon (teal ££, label "Work Rota")
- `view/`: the view-only icon for his wife (teal eye, "Asim's Rota")

To add one: open the page in Chrome or Safari, tap Share, then Add to Home Screen.

Both pages open the Work Rota & Ledger app at https://claude.ai/artifact/DEQSHvutLuVkfj6yS8TJif (from 23 Nov 2026).
The view page only works for someone the app has been shared with.
